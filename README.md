# NTK Chat – Realtime Chat Application

**Live Demo:** [https://ntk-chat.vercel.app](https://ntk-chat.vercel.app)

## Frontend

TypeScript, React.js, Tailwind CSS, shadcn/ui, Zustand.

## Backend

TypeScript, Node.js, Express.js, MongoDB.

## Real-time & AI

Socket.IO, Google Gemini AI (Generative AI).

## Authentication

JWT, Bcrypt, OAuth2.

## Infrastructure

Cloudinary, Brevo.

## Description

Developed core features of a chat application such as direct messaging (1-1), group chat, user online/offline presence, friend system, and other real-time functionalities powered by Socket.IO.

Built an authentication system using Access Tokens (JWT) and Refresh Tokens to maintain user sessions.

Utilized Brevo for email OTP delivery and Cloudinary for media storage, with OAuth2 integration for Google login.

Integrated a chatbot powered by Google Gemini for conversational interaction.
